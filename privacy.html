PAZ

1. Introdução

O PAZ — Escudo Inteligente de Chamadas é um aplicativo móvel desenvolvido pela Aistudio que tem como única finalidade proteger o usuário contra chamadas telefônicas indesejadas (spam, robocalls, telemarketing e números desconhecidos).

Esta política descreve de forma clara e transparente quais informações o PAZ não coleta, quais permissões do sistema solicita e como os dados do usuário são tratados em todas as versões (Freemium, PRO e PRO Empresarial).

2. Dados Que Não Coletamos

O PAZ foi projetado com privacidade por design. O aplicativo NUNCA coleta, armazena ou transmite:

  • Dados pessoais — nome, e-mail, CPF, endereço, data de nascimento ou qualquer identificador do usuário.
  • Conta ou cadastro — não exige criação de conta, login ou senha.
  • Números de telefone — processados exclusivamente no próprio aparelho, nunca saem dele.
  • Agenda de contatos — mesmo com permissão READ_CONTACTS, a consulta é 100% local.
  • Histórico de chamadas — fica apenas no banco Room (SQLite) do aparelho.
  • Localização geográfica — nunca solicita acesso à localização do dispositivo.
  • Analytics ou telemetria — não há SDKs de rastreamento, cookies ou monitoramento de uso.

Resumo: o PAZ não sabe quem você é. Ele ouve as chamadas recebidas (sem gravação de áudio), decide na hora se deve tocar ou silenciar, e registra a decisão no histórico local do seu celular.

3. Permissões do Sistema Utilizadas

  • CallScreeningService — permissão nativa do Android Telecom para interceptar chamadas recebidas antes de tocarem. Essencial para o funcionamento.
  • READ_CONTACTS (opcional) — libera automaticamente chamadas de contatos salvos. O usuário pode desativar. Consulta 100% local.
  • INTERNET — apenas para baixar a lista pública de patrocinadores do Supabase (uma vez a cada 24h). Única comunicação de rede.
  • FOREGROUND_SERVICE e SYSTEM_ALERT_WINDOW — usadas para exibir a interface em primeiro plano.

4. Dados Armazenados Localmente

  • Histórico de chamadas (número, data/hora, motivo) — 3 dias no gratuito, 60 dias no PRO. Limpeza automática.
  • Preferências do usuário (escudo, regras, modo não perturbe, zoom de texto) — tudo local.
  • Token do Supabase (criptografado, se configurado) — apenas para validar conexão.
  • Lista de números bloqueados — até 3 no gratuito, ilimitada no PRO.

Todos apagados ao desinstalar o app.

5. Supabase — Serviço Opcional

Integração opcional. Apenas consultas de leitura pública à tabela sponsors (patrocinadores). Nenhum dado pessoal ou de chamada é enviado. Conexão HTTPS.

6. Compartilhamento com Terceiros

O PAZ não compartilha dados. Não há SDKs de publicidade, analytics, redes sociais ou servidores de coleta.

7. Segurança

Código-fonte aberto no GitHub para auditoria. Toda triagem é local. Credenciais Supabase armazenadas no cofre do Android.

8. Controle do Usuário

  • Desativar escudo — toque em PAUSA.
  • Revogar permissões — nas configurações do Android.
  • Excluir dados — o app já expurga registros antigos automaticamente.
  • Desinstalar — todos os dados locais são apagados.
